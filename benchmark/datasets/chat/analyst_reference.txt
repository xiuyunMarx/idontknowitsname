Unit tables, formulas and rounding rules.

== Data units (decimal, in bits) ==
1 bit = 1 bits
1 byte = 8 bits
1 kilobyte = 8000 bits
1 megabyte = 8000000 bits
1 gigabyte = 8000000000 bits
1 terabyte = 8000000000000 bits
1 kilobit = 1000 bits
1 megabit = 1000000 bits
1 gigabit = 1000000000 bits

== Time units (in seconds) ==
1 second = 1 seconds
1 minute = 60 seconds
1 hour = 3600 seconds
1 day = 86400 seconds
1 week = 604800 seconds

== Formulas ==
throughput_total = rate_per_unit * units_elapsed
used_capacity = node_count * capacity_per_node * fill_fraction
annual_cost = unit_price * units * 12
percent_of = value * percent / 100
chunks = floor(budget / chunk_size); remainder = budget - chunks * chunk_size

== Rounding rules ==
Keep full precision through calculate; round only the final answer to 2 decimals. State units in every answer. Use calculate for every arithmetic step.

# Recompute CDF figures and data

Generated by `python benchmark/recompute_cdf.py` from the server logs
`results/coding_sweep/<arm>_c<N>.log` (codeAgent) and `results/fact_sweep_h16_inputfirst/<arm>_c<N>.log` (FactCheck).

## Files
- `codeAgent/recompute_cdf_c<N>.{pdf,png}`, N = 12..44 and `FactCheck/recompute_cdf_c<N>.{pdf,png}`, N = 8..18:
  CDF over all LLM calls of the recomputed fraction of the prompt, five arms per figure.
- `codeAgent/recompute_cdf_calls.csv`, `FactCheck/recompute_cdf_calls.csv`: one row per LLM call, the exact rows
  each curve is drawn from.

## Definitions
- `recomputed = prompt_tokens - cached_device - cached_host` (tokens prefilled from scratch for that call)
- `recomputed_fraction = recomputed / prompt_tokens`; the CDF is the empirical distribution of this value over
  all calls of one (concurrency, arm) run.
- Included: every call of every measured session. Excluded: the two warmup sessions; for calls with typed
  retries only the first turn is counted (a retry re-sends the prompt plus feedback, almost fully cached).
- `arm`: `lruraw` = vanilla SGLang HiCache LRU, `cachescout` = CacheScout, `kvonly` = planner only (`--no-relayout`),
  `lru` = re-layout only, `ours` = re-layout + planner.
- `site` / `site_invocation`: call site and its k-th invocation within the session, from the server's `[call]`
  lines. Empty for CacheScout, whose server sees only chat messages and logs no call-site name.
- `call_index`: k-th LLM call of the session, all sites pooled (1-based). `session_pid`: the session process id.
- `ttft_ms`: server-side time to first token for the call.

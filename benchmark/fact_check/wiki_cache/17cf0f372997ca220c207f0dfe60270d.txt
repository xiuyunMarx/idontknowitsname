Title: Chromium (web browser)
URL: https://en.wikipedia.org/wiki/Chromium_(web_browser)
Excerpt: Chromium is a free and open-source web browser project, primarily developed and maintained by Google. It is a widely used codebase, providing the vast majority of code for Google Chrome and many other browsers, including Microsoft Edge, Opera, Vivaldi, Brave, Samsung Browser and Ungoogled Chromium. The code is also used by several app frameworks.

\section{Related Work}
\label{sec:related_works}
\para{Application-level information for serving} Parrot~\cite{lin2024parrot} represents intermediate results as semantic variables and uses their producer--consumer relationships for scheduling and prefix-aware placement. Teola~\cite{tan2025teola} exposes operators finer than a call, removes unnecessary dependencies, computes available prefixes while upstream operators produce the remaining inputs, and forwards partial outputs downstream. 

\para{Prompt construction for prefix reuse} DSPy's adapters and NOOA fix a component order by convention or by developer labels~\cite{dspy2026chatadapter,furgale2026nooa}, and the SGLang frontend moves constant components forward at compile time~\cite{zheng2024sglang}. For relational analytics, \citet{liu2025optimizing} order rows and the fields within them jointly, grouping rows that share field values and using functional dependencies to expose further sharing. Reuse can also go beyond matching prefixes: Prompt Cache~\cite{gim2024promptcache} precomputes prompt modules at prescribed positions, and CacheBlend~\cite{yao2025cacheblend} recomputes the tokens whose attention crosses chunk boundaries when combining cached chunks.

\para{KV-cache scheduling across execution gaps} Serving systems also steer the KV-cache according to tool-call gaps in ReAct agents. InferCept~\cite{abhyankar2024infercept} weighs the cost of keeping, swapping, and recomputing KV-cache per interruption to make scheduling decisions; Continuum~\cite{li2025continuum} holds the idle KV-cache for a time-to-live derived from observed inter-invocation delays; TokenCake~\cite{bian2026tokencake} estimates the tool call's duration, offloads idle KV to the host, and restores it before the expected return.

\section{Design}
\label{sec:design}

To bridge the gap between the structured nature of programmatically generated prompts and the opaque treatment they receive at the serving layer, we propose \sysname, an effcient serving engine for program-integrated LLM agents. \sysname is a
compiler-server co-design that identifies and exploits prompt heterogeneity for more efficient KV-cache management. On the compiler side, \sysname performs static analysis to recover the sharing scopes and lifetimes of prompt components, and proactively re-lays out prompt bindings to expose longer reusable prefixes. On the server side, \sysname uses the recovered heterogeneity information to guide KV-cache scheduling, including cache prefetching, protection, and prediction-guided eviction. Together, these mechanisms enable the serving system to manage KV cache according to the expected reuse and lifetime of different prompt components rather than treating each request as an undifferentiated token sequence.

Existing agent serving systems schedule the KV-cache at the level of requests or prefixes. However, we observe that prompts in agent LLM invocations are not monolithic: their components differ in sharing scope, lifetime, and evolution pattern. Neglecting this heterogeneity leads to suboptimal KV-cache scheduling, but a system that sees only the token sequence can hardly identify and exploit it, because semantic boundaries and behavior differences are buried in the tokens. Our insight is that frameworks exposing model invocations through structured programming abstractions make this information available. We therefore present \sysname, a compiler-serving co-design that analyzes the agent program to recover intra-prompt heterogeneity and exploits it for KV-cache scheduling. Our evaluation shows that \sysname achieves up to 1.90$\times$ lower average JCT, 4.49$\times$ lower average TTFT, and 1.46$\times$ higher throughput than Vanilla SGLang.

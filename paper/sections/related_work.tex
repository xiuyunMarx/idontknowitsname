\section{Related Work}
\label{sec:related-work}

\paragraph{LLM programming abstractions.}
MTP and its ByLLM implementation derive LLM operations from typed declarations and semantic information~\cite{dantanarayana2025mtp}. DSPy separates declarative signatures and modules from prompt construction and optimization~\cite{khattab2024dspy}. NVIDIA Object-Oriented Agents embeds LLM behavior in Python objects~\cite{furgale2026nooa}, while SIGIL compiles skill documents into typed harnesses with explicit control flow~\cite{dantanarayana2026sigil}. These systems make program structure available during application construction. \sysname studies how the resulting structure can inform serving: named bindings expose value evolution and sharing that token-prefix lookup alone does not identify. It consumes supplied templates or infers them from observed requests, and uses the recovered structure for cache management.

\paragraph{Memory-efficient inference and hierarchical caching.}
vLLM's PagedAttention improves KV allocation and sharing through paged memory management~\cite{kwon2023pagedattention}. SGLang combines a structured programming interface with RadixAttention and cache-aware scheduling~\cite{zheng2024sglang}. Sarathi-Serve uses chunked prefill to improve the throughput--latency tradeoff~\cite{agrawal2024sarathi}. CachedAttention retains conversation KV in a hierarchy and overlaps data movement with computation~\cite{gao2024cachedattention}; Mooncake builds a distributed cache and scheduling architecture around KV reuse~\cite{qin2025mooncake}. These mechanisms provide allocation, lookup, transfer, and execution support. \sysname builds on SGLang and adds decisions about the serialized prefix and its future demand, using binding lifetimes to determine what can be reused and prepared.

\paragraph{Modular and non-prefix attention reuse.}
Prompt Cache explicitly defines reusable prompt modules through schemas and manages their positions for attention-state reuse~\cite{gim2024promptcache}. CacheBlend targets inputs assembled from multiple text chunks, reusing cached states beyond the common prefix and selectively recomputing tokens to restore cross-chunk interactions~\cite{yao2025cacheblend}. These works recognize that a prompt contains reusable components. \sysname instead exposes common prefixes by reorganizing labelled bindings according to their observed evolution, then uses ordinary exact prefix caching on the resulting requests. It does not transplant KV tensors computed under a different preceding context. Exact cache reuse for a transformed request does not imply that the transformation preserves model outputs; the task-quality evaluation addresses that separate question.

\paragraph{Workflow-aware agent serving.}
KVFlow represents an agent schedule as an Agent Step Graph and uses distance to future execution for node-level eviction and overlapped prefetching~\cite{pan2025kvflow}. PBKV predicts several future agent invocations in dynamic workflows using historical executions and current context, then conservatively guides eviction and prefetching~\cite{zheng2026pbkv}. CacheScout learns agent transitions online without a predefined workflow graph~\cite{zhang2026cachescout}. Continuum uses bounded retention through KV-cache time-to-live to preserve continuity across tool calls~\cite{li2025continuum}. Pythia exposes workflow semantics through a serving interface to drive speculative cache management, lookahead scheduling, and autoscaling~\cite{yu2026pythia}.

These systems establish the value of anticipating agent execution, including managing individual cache nodes and shared prefixes. \sysname's distinction is the coupling of that anticipation with the structure inside generated prompts. It learns which bindings are constant, copied, extended, or volatile; uses this information to change the reusable prefix; and reconstructs the known portion of predicted requests to guide preparation and retention. Thus, workflow prediction supplies the likely destination and time of reuse, while binding analysis supplies the content and boundary of the reusable prefix.

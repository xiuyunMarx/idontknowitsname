\section{Related Work}
\label{sec:related-work}
\paragraph{KV-cache reuse}
PagedAttention~\cite{kwon2023pagedattention} and SGLang~\cite{zheng2024sglang} reuse KV along an exact shared prefix, and hierarchical caches~\cite{gao2024cachedattention,qin2025mooncake,sglang2026hicache} extend its capacity beyond device memory. Prompt Cache~\cite{gim2024promptcache} and CacheBlend~\cite{yao2025cacheblend} reuse KV beyond the prefix, by fixing module positions in a schema or by selectively recomputing tokens of concatenated chunks. \sysname keeps exact prefix matching and instead changes the prompt so that reusable components form the prefix; it is orthogonal to position-independent reuse.

\paragraph{Existing agent serving systems}
KVFlow~\cite{pan2025kvflow}, Continuum~\cite{li2025continuum}, CacheScout~\cite{zhang2026cachescout}, PBKV~\cite{zheng2026pbkv}, and Pythia~\cite{yu2026pythia} predict future execution from step graphs, observed tool-call delays, learned transitions, or workflow histories, and use these predictions to retain and prefetch KV between calls. 

\paragraph{Existing Exploitation of prompt structure}
Agent frameworks~\cite{dantanarayana2025mtp,khattab2024dspy,furgale2026nooa,dantanarayana2026sigil} know the structure of the prompts they generate. Where they arrange it for reuse, they apply one hand-chosen convention to every call site, such as NOOA's static, history, and volatile regions. Parrot~\cite{lin2024parrot} passes application structure to the server through Semantic Variables that developers declare, but serves prompts in the layout the application wrote. SGLang's frontend~\cite{zheng2024sglang} reorders prompt statements to lengthen the constant prefix, but has GPT-4 choose the order, which its authors note is not yet reliable.
